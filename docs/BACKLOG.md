# Бэклог ядра «семейство РК»

## Решить

- (решено 2026-11-07: имя `rk`; ПЗУ и знакогенераторы Emu80 в `.kg`; Партнёр в первой версии; `radio86rk.kg` заменяется; кадровый буфер.)

## Проверить

- Порядок записи файла ленты: у нас файл пишется до старта Монитора, у Emu80 после (см. HARDWARE, «Файлы»). Из ~240 программ Emu80 рабочую область Монитора задевает только `BOOT.RK` (загрузчик SD vinxru, в ядре не нужен). Править, если найдётся программа, которая от этого ломается.

## Потом

- Микроша: внешнее ПЗУ (ROM-диск) 8000–BFFF; чтение 8000–BFFF без ПЗУ в Emu80 даёт слово состояния процессора, у нас FF; дисковод (RK-DOS).
- Апогей: SD-контроллер вместо ROM-диска (`apogey-sd.conf`); режим «градации серого» Emu80.

- Партнёр: модули дисковода (ВГ93, `fddrom.bin`, образы `.cpm`, CP/M по `E2`) и SD-контроллера vinxru (`sdrom.bin`, `E1`); другие версии ПЗУ Партнёра.

- KR-03, «Криста», RK-DOS, Z80, шрифт в ОЗУ (`RkRamFontRenderer`), Pixeltron.
