# Железо семейства РК

Источник: конфиги Emu80 v4 (`dist/rk86/rk86.conf`, `dist/mikrosha/mikrosha.conf`, `dist/apogey/apogey.conf`, `dist/mikro80/mikro80.inc`) и `Apogee.sv` из Apogee_MiSTer. Расхождения — **проверить**.

Частоты (РК86, Микроша, Апогей): процессор, ВТ57 и ВИ53 — 1 777 777 Гц (16 МГц / 9), ВГ75 — 1 333 333 Гц (знаки по 6 точек, 8 МГц точек). Микро-80: процессор 2 МГц.

## Радио-86РК

| Адрес | Что |
|---|---|
| 0000–7FFF | ОЗУ 32 КБ (экран по адресу из канала 2 ПДП, у Монитора 76D0) |
| 8000–9FFF | ВВ55 клавиатуры (A — опрос столбцов, B — строки, C — РУС/ЛАТ, УС, СС, магнитофон) |
| A000–BFFF | ВВ55 №2 (пользовательский) или ВИ53 (вариант с таймером) |
| C000–DFFF | ВГ75 (C000 — данные, C001 — команды / состояние); с SDOS: ВГ75 C000–CFFF, SD-адаптер D000–DFFF |
| E000–EFFF | запись — ПДП ВТ57; чтение — ПЗУ DOS / SDOS (4 КБ) |
| F000–F7FF | запись — ПДП; контроллер дисковода RK-DOS на ВВ55 (вариант) |
| F800–FFFF | чтение — ПЗУ Монитора (2 КБ); запись — ПДП |

Старт с F800. Звук — вывод INTE процессора (команды EI / DI), выход магнитофона — порт C.

## Микроша

| Адрес | Что |
|---|---|
| 0000–7FFF | ОЗУ 32 КБ |
| 8000–BFFF | внешнее ПЗУ (ROM-диск, вариант) |
| C000–C7FF | ВВ55 клавиатуры: **B — опрос, A — чтение** (наоборот против РК86); C: D0 магнитофон, D1 вентиль звука, D2 вентиль канала 2 ВИ53; C5 РУС/ЛАТ, C6 УС, C7 СС |
| C800–CFFF | ВВ55 №2: PB7 — второй набор знакогенератора (`MikroshaPpi2Circuit`) |
| D000–D7FF | ВГ75 |
| D800–DFFF | ВИ53 (звук) |
| F000–F7FF | дисковод (вариант) |
| F800–FFFF | ПЗУ Монитора (2 КБ), запись — ПДП |

## Апогей БК-01

| Адрес | Что |
|---|---|
| 0000–EBFF | ОЗУ |
| EC00–ECFF | ВИ53 (звук) |
| ED00–EDFF | ВВ55 клавиатуры (как РК86) |
| EE00–EEFF | ВВ55 №2: ROM-диск (EXTROM) или SD-контроллер |
| EF00–EFFF | ВГ75 |
| F000–FFFF | чтение — ПЗУ (4 КБ); запись — ПДП |

Старт с F800. Цвет — атрибуты ВГ75: R = нет подсветки, G = нет GPA1, B = нет GPA0 (Emu80 и Apogee_MiSTer совпадают). Набор знакогенератора — INTE. Звук — сумма трёх каналов ВИ53 и выход магнитофона. ROM-диск на ВВ55 №2: порт A читает байт `{банк, PC[6:0], PB}`, банк — PB[3:0] по фронту PC7 (512 КБ).

Клавиатура Микроши (Emu80 `m_KeyMatrixMikrosha`): матрица РК86, повёрнутая набок — клавиша строки r, столбца c таблицы РК86 здесь столбец r, бит c (цифры, буквы, знаки); строки 0 и 1 свои (пробел, АР2, ТАБ, ПС, ВК, СТР, ←, →; ↑, ↓, ↖, F1–F5), столбец 7 бит 7 — ЗБ.

## Микро-80

Без ВГ75 и ПДП, процессор 2 МГц. ОЗУ 0000–DFFF, видеоОЗУ E000–EFFF, ОЗУ F000–F7FF, ПЗУ F800–FFFF (старт с F800).

Экран (Emu80 `Mikro80Renderer`): 64 × 32 знака 6 × 8; E800–EFFF — коды (7 бит), E000–E7FF — атрибуты, бит 7 атрибута **следующей** ячейки инвертирует ячейку (кроме последней в строке). Строка знаков — 10 линий (8 + 2 тёмные), кадр 384 × 320. У нас строка 9 линий (8 + 1), чтобы 32 строки (288 линий) поместились в окно буфера 512 × 300.

Устройства на портах ввода-вывода (IN / OUT; у моделей с ВГ75 такие циклы идут в память по адресу {n, n}, как на настоящих машинах):

| Порт | Что |
|---|---|
| 01 | магнитофон: D0 — выход (и единственный звук), чтение D0 — вход |
| 04–07 | ВВ55 клавиатуры, адрес инвертирован (07 — порт A): A — опрос, B — чтение (бит 7 всегда 0), PC0 РУС/ЛАТ, PC1 УС, PC2 СС |
| 40–4F | страница RAM-диска: первый нулевой бит байта — страница 1..8, FF — основная память |
| A0–A3 | ВВ55 ROM-диска: порт A читает байт `{PC, PB}` (до 64 КБ) |

RAM-диск (Emu80 `Ut88AddrSpaceMapper`): при выбранной странице в неё идут только обращения к стеку (бит D2 слова состояния), 8 страниц по 64 КБ.

Мониторы: родной (`mikro80.rom`, «*МИКРО/80* MONITOR», `>`) и РК-совместимый (`mikro80rk.rom`, «M/80K», `-->`; при холодном старте около 3 с проверяет память). Оболочке ROM-диска нужен РК-совместимый: `R7E00,7FFF`, `G`. Матрица клавиатуры (Emu80 `m_keyMatrixMikro80`): 0–6; 7, 8, 9, :, ;, «,», −; ., /, @, A–D; E–K; L–R; S–Y; Z, [, \, ], ^, ЗБ, пробел; →, ←, ↑, ↓, ВК, СТР, ↖. Файлы `.rk8`.

## Файлы

`.rk`, `.rkr`, `.gam` (РК86), `.rkm` (Микроша), `.rka` (Апогей): начальный и конечный адрес, данные, контрольная сумма; у части файлов впереди синхробайт E6. **проверить** по `RkFileLoader` Emu80.
