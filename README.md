# RK family core for Karabas Go / Mini / Mini G

Radio-86RK, Mikrosha, Apogey BK-01 and Mikro-80 in one core for the Karabas Go family of boards (Xilinx Spartan-6 XC6SLX25). Work in progress: plan and build skeleton. It is to replace [karabas-go-core-rk86](https://github.com/andykarpov/karabas-go-core-rk86).

- [docs/PLAN.md](docs/PLAN.md): research, decisions and phases (Russian).
- [docs/HARDWARE.md](docs/HARDWARE.md): memory maps and ports (Russian).
- [docs/BACKLOG.md](docs/BACKLOG.md): open questions (Russian).
